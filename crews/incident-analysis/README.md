# Incident Analysis

Analyzes production software and infrastructure incidents from alerts, logs, deployment records, tickets, chat transcripts, runbooks, architecture material, and operator statements. Reconstructs a sourced timeline, distinguishes proximate triggers from contributing conditions, evaluates detection and response quality, identifies uncertainty and conflicting evidence, and produces blameless corrective actions with owners and verification criteria. The crew never asserts root cause beyond what evidence supports and never infers individual intent or competence.

## Agents

| ID | Name | Role |
| --- | --- | --- |
| `director` | Incident Analysis Director | Orchestrator who interprets incident scope, performs information sufficiency checks, delegates to all specialists and the synthesizer, and coordinates the final output |
| `timeline_analyst` | Timeline Analyst | Specialist who reconstructs a sourced, ordered incident timeline from alerts, logs, tickets, and transcripts, flagging timestamp conflicts, gaps, and coverage |
| `telemetry_analyst` | Telemetry Analyst | Specialist who analyzes metric, log, and alert data to surface anomalies, quantify impact, and produce evidence-backed signal visualizations |
| `change_analyst` | Change Analyst | Specialist who reviews deployment records, configuration changes, and external dependency changes to identify contributing changes correlated with the incident window |
| `systems_analyst` | Systems Analyst | Specialist who maps system architecture and conditions to causal hypotheses, comparing hypotheses against evidence without asserting root cause |
| `response_analyst` | Response Analyst | Specialist who evaluates detection latency, response timeliness, escalation paths, and runbook effectiveness against documented incident timelines |
| `corrective_action_reviewer` | Corrective Action Reviewer | Specialist who validates corrective actions for completeness, verifiability, coverage of failure modes, and absence of duplicates |
| `synthesizer` | Incident Report Synthesizer | Synthesizer who composes the final blameless incident report from specialist findings, weaving citations, visualizations, and structured outputs into the requested answer mode |

## Custom tools

| ID | Description |
| --- | --- |
| `event_timeline_builder` | Deterministically normalizes and orders incident events from heterogeneous sources. Returns sorted events, timestamp conflicts, duplicate candidates, gap intervals, and source coverage. |
| `causal_hypothesis_matrix` | Compares causal hypotheses against available evidence without asserting a root cause. Returns a support/contradiction matrix, unsupported hypotheses, discriminating evidence needed, and confidence caveats. |
| `action_item_validator` | Verifies the quality and completeness of corrective actions from an incident review. Returns missing fields, unverifiable actions, duplicate actions, and coverage by failure mode. |

## Answer modes

`summary` (Incident Brief), `light` (Review Memo), `extended` (Full Incident Analysis), `project_plan` (Corrective Action Plan), `roadmap` (Reliability Roadmap)

Default: `extended`
