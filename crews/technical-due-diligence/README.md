# Technical Due Diligence

Evaluates a software system or technology company from repository exports, architecture documents, dependency inventories, security reports, operational evidence, and public technical sources. Produces evidence-linked findings with explicit uncertainty, severity and confidence scores, and prioritized remediation. Strictly distinguishes observed evidence, inference, and missing evidence — never invents repository facts.

## Agents

| ID | Name | Role |
| --- | --- | --- |
| `director` | Director | Orchestrator who interprets the due-diligence request, performs information-sufficiency checks, delegates to all specialists and the synthesizer, and coordinates the final output |
| `architecture_analyst` | Architecture Analyst | Specialist who evaluates system architecture, design patterns, scalability, and technical debt from uploaded documents and the knowledge base |
| `security_analyst` | Security Analyst | Specialist who assesses security posture, vulnerability reports, threat surface, and compliance signals from documents and public sources |
| `dependency_analyst` | Dependency Analyst | Specialist who inventories third-party dependencies, assesses license risk, vulnerability exposure, and maintenance health using deterministic risk triage |
| `reliability_analyst` | Reliability Analyst | Specialist who evaluates operational reliability, SLAs, incident history, observability maturity, and quantitative availability estimates from documents and calculations |
| `evidence_auditor` | Evidence Auditor | Specialist who audits all findings for evidence coverage, flags unsupported claims and high-severity findings lacking references, and produces confidence distributions |
| `remediation_planner` | Remediation Planner | Specialist who converts audited findings into prioritized remediation actions with owners, effort estimates, and verification criteria |
| `synthesizer` | Synthesizer | Composer who assembles specialist findings into a coherent, evidence-linked report with visualizations, citations, and explicit uncertainty disclosures |

## Custom tools

| ID | Description |
| --- | --- |
| `dependency_risk_matrix` | Deterministic triage of an array of dependency records. Returns normalized risk rows with reasons, and aggregate counts by risk tier. |
| `evidence_coverage_score` | Deterministic audit of an array of finding objects. Returns evidence coverage ratio, unsupported high-severity findings, confidence distribution, and audit flags. |

## Answer modes

`summary` (Decision Brief), `light` (Review Memo), `extended` (Full Technical Report), `project_plan` (Remediation Plan), `roadmap` (Risk-Reduction Roadmap)

Default: `extended`
